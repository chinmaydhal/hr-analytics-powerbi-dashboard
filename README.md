# HR Analytics Power BI Dashboard

Role-based HR and executive **Power BI** reporting solution designed to analyze employee activity, workforce productivity, and operational bottlenecks.

## Key Features
- **Role-Based Reporting:** Tailored views for HR teams and executive leadership with Row-Level Security (RLS) support.
- **Employee Activity & Productivity:** Track utilization, task completion trends, attendance, and departmental output.
- **Operational Bottlenecks:** Identify workflow delays, resource allocation gaps, and high-friction stages across teams.

## Performance & Data Modeling
- **4x Report Performance Improvement:** Optimized the semantic data model, removed redundant columns, and refactored complex **DAX** measures to achieve a 4x faster report load and refresh experience.
- **Star Schema Architecture:** Structured fact and dimension tables for scalable, maintainable business intelligence.

## Tech Stack
- **BI & Visualization:** Power BI
- **Query & Calculations:** DAX, Power Query
- **Concepts:** Data Modeling, Business Intelligence, HR Analytics
